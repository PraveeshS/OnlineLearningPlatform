📚 Online Learning Platform

A Django-based web application designed to facilitate digital learning by connecting instructors and students. The platform allows instructors to create and manage courses, while students can browse, purchase, and engage with content. It also includes secure authentication, role-based dashboards, and two-factor email OTP login.

For Instructors
-Instructor dashboard with course management
-Add, update, and delete courses
-Upload course materials (videos, links, documents)
-View enrolled students

For Students
-Student dashboard with enrolled courses
-Browse and purchase available courses
-View course content and receive updates

Authentication
-Role-based login system (Student/Instructor)
-Secure authentication using email-based OTP (via pyotp)
